# Pumpkin Guy

Pumpkin Guy is a not-so-spooky adventure game about one little pumpkin trying to get his body back.

Right now, it is a pixel-art platformer with parkour, exploration, and plenty of places to jump around. Later on, the plan is to turn it into a bigger scavenger hunt with survival, weird surprises, and maybe a few jumpscares.

## Planned modes

**Adventure** - Explore, platform, and find the next piece.
**Scavenger Hunt** - Search the map and collect everything you can.
**Survival** - Stay alive while the world gets a lot less chill.
**Jumpscare Mode** - For when “not so spooky” stops being true.
